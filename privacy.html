Privacy policy

Last updated 9 November 2026

Who uses Tether

Tether is a personal tool with a single user: its owner. It is not offered to the public, and nobody else can authorise it to access their account.

What data Tether accesses

With the owner's consent, Tether requests read-only access to the owner's Gmail (gmail.readonly). It reads messages only when the owner's own assistant asks it to, for example to search or summarise the owner's email.

How data is stored

The Google access token is stored only on the owner's private server and is never published or shared. Email content is fetched on demand and is not copied into any other database. Tether keeps a log of which tools were used and when, not of message contents.

Sharing

Tether does not sell, share or transfer Google user data to anyone. Content is passed only to the AI assistant that the owner runs, to answer the owner's own requests.

Google API Services User Data Policy

Tether's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time from your Google Account permissions.
