Tether

The one line that ties my accounts to my own AI assistants.

Tether is a personal, self-hosted tool. It runs on a private server that I own and connects my own accounts (such as Gmail) to AI assistants that I run myself. It is not a public service: it has a single user, its owner, and no one else can sign in to it.

Tether keeps the account credentials on that server and gives assistants only narrow, read-only tools, so the assistants never see passwords or tokens.
